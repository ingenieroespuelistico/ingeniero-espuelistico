Abre los archivos con el Bloc de notas o, mejor, con Visual Studio Code. Guarda y recarga la página con Ctrl + F5.

MONEDAS
- La moneda base es SIEMPRE el peso colombiano. Tú solo escribes precios en pesos.
- Si el cliente elige otra moneda (bandera arriba o "Elige tu moneda local"), la página
  convierte con la tasa del día que consulta sola en internet. Si esa consulta falla,
  usa las tasas de respaldo de js/precios.js.
- El cobro siempre se hace en pesos (Mercado Pago) o en dólares (PayPal / Western Union).

DESPUÉS DE EDITAR
- Revisa catálogo, tabla de precios y un pedido de prueba.
- Cuando la página esté en internet: sube el cambio a GitHub y Netlify la actualiza sola
  en 1–2 minutos. (Más adelante podemos poner un panel web con usuario y clave para
  editar precios desde el celular.)

PAGOS Y AVISOS (ya funcionan)
- En Colombia el cliente paga en línea con Mercado Pago (PSE, tarjeta, Efecty, Bancolombia).
  El servidor recalcula precios y envío; nadie puede cambiar el precio desde su navegador.
- El envío se cotiza solo con Envia y se cobra la transportadora más barata de la lista.
- Cada pago aprobado o pendiente te llega por Telegram con productos, cliente y dirección.
- Los tokens están guardados en Cloudflare (Worker → Settings → Variables and Secrets).
  Para revisar que todo esté conectado abre: /api/salud?revisar=1
